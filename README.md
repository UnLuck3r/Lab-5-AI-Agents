# LangGraph HR Assistant Agent 🤖

> **Лабораторная работа №5** по курсу *«AI Agents for Enterprise Processes Automation»*  
> **Студент:** Бахапов Ырыскелди  
> **Стек:** Python 3.10+, LangGraph 1.2+, LangChain, Groq API (Qwen 3.8 27B), Pydantic v2, dotenv  

Автономный HR-ассистент первого уровня поддержки на базе **LangGraph**. Граф обрабатывает входящие заявки сотрудников, классифицирует их категории, проводит уточняющие диалоги через механизм **Human-in-the-Loop (`interrupt()`)** при неоднозначности и перенаправляет нерешаемые вопросы на человека в безопасную **fallback-ветку (`escalate`)**.

---

## 🛠️ Архитектура и функциональные возможности

1. **Маршрутизация заявок:** Автоматически распределяет обращения по 4 категориям (`vacation`, `sick_leave`, `certificate`, `payroll`).
2. **Human-in-the-Loop (HITL):** При уверенности классификации ниже порога (`< 0.7`) или неоднозначном запросе граф приостанавливается через `interrupt()` для получения ответа пользователя и возобновляется с помощью `Command(resume=...)`.
3. **Ограничение циклов:** Количество уточнений ограничено (`MAX_CLARIFY = 2`). При превышении лимита запрос безопасно передается HR-специалисту.
4. **Fallback-защита:** Ошибки валидации, сбои API или пустые запросы (`< 3` символов) не ломают скрипт, а уводятся в узел `escalate`.
5. **Защита от Prompt Injection:** Ответы формируются строго по изолированному регламенту `HR_POLICY`, предотвращая несанкционированные действия (например, "одобрение" отпуска).

## 🚀 Быстрый запуск

### 1. Настройка виртуального окружения

```bash
# Клонируйте репозиторий / перейдите в папку проекта
cd hr_langgraph

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установите зависимости
pip install -U langgraph langchain-groq langchain-ollama python-dotenv pydantic
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
GROQ_API_KEY=gsk_ваш_настоящий_ключ_groq
GROQ_MODEL=qwen/qwen3.8-27b
USE_LLM=1
```

*(Для работы без API ключа установите `USE_LLM=0` — агент переключится на детерминированный ключевой классификатор).*

## 🧪 Запуск автотестов

Для запуска полного набора из 10 тестовых сценариев (T01–T10) выполните:

```bash

USE_LLM=0 python tests.py
```
